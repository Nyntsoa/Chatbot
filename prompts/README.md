# Documentation du prompt

Ce dossier contient les consignes de base pour le modele local.

## Objectif
Le fichier `system_prompt.txt` sert a cadrer les reponses :
- Demander au modele de repondre uniquement avec les extraits trouves dans le dossier `docs/`.
- Eviter les inventions si l'information n'est pas dans les textes.
- Garder un ton simple et orienter vers la scolarite si besoin.
